# 🤖 AI 学习计划生成器

一个由 AI 辅助编写的智能学习规划工具，专为大学生设计，帮助合理分配学习时间。

## ✨ 项目特点
- 🧠 **模拟AI决策**：根据认知科学规律（黄金学习时段、精力分配）自动排课。
- 📚 **智能匹配**：内置多学科推荐时长，并支持用户自定义科目。
- ☕ **科学休息**：根据学习强度（轻松/适中/密集）智能插入休息时间。
- 🎯 **零依赖**：仅使用 Python 标准库，无需安装任何第三方包。

## 🚀 快速开始
1. 确保已安装 Python 3.6+。
2. 在终端运行：
   ```bash
   python study_planner.py
   ```
3. 按提示输入：
   - **科目**：用英文逗号分隔（例如：`数学,英语,编程`）
   - **时长**：今天想学几个小时（例如：`4`）
   - **强度**：`轻松` / `适中` / `密集`

## 📝 关于“AI”的说明
本项目中的“AI”并非神经网络大模型，而是**基于规则的决策算法**（Rule-based System）。它模拟了AI规划师的行为：
1. **数据解析**：理解用户输入的自然语言（科目、时长）。
2. **知识调用**：内置学科-时长映射表。
3. **约束求解**：在总时长限制下，合理安排每个科目的开始结束时间，并插入休息。
4. **优化输出**：根据黄金学习时段标记高效时间。
